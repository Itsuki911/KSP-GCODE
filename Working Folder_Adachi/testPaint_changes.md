# testPaint.gcode 監査後の追加修正（2026-11-18）

対象はこのフォルダの `testPaint.gcode` のみ。`gcodes/*.gcode`、printer.cfg、Mainsailのマクロは変更していません。

反映した内容：

- 開始時と正常終了時に閉弁指令を追加。パージ開閉前にM400を入れ、直前の軸移動を完了させます。
- SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0を追加。このプログラムは機械座標に対するXYZオフセット0を開始条件にします。既存の治具・工具オフセットを意図的に使う運用とは、そのまま併用しないでください。
- M220は100%とし、各移動にFを明示。前の修正版の要求速度を維持し、XY移動／塗布F7500、パージF5625、絞りF1500、Z単独F1200としています。Xはdegなので、これを一定の表面mm/sとは解釈できません。既存の実行時速度・加速度制限は強制的に引き上げません。
- パージ開始をX285に戻し、元ファイルと同じ17片道・総340度に修正。閉弁タイミングの停止条件も変更しているため、同一液量を保証するものではありません。
- Circle1のY35経由点を戻し、Z24でY45へ進んでから垂直下降します。既存修正版の作業Zと退避Zは維持しています。
- 正常終了時は移動完了後、M220 S100／F1500を残します。「安全確認済み」と読めるコメントを訂正しました。

バルブ応答時間はユーザー確認で未測定のため、固定G4待機は挿入していません。必要な測定済み待機を追加する箇所をコメントで示しました。M400は軸移動完了待ちであり、サーボ到達・閉弁・液の停止を確認する命令ではありません。

異常停止・キャンセル時はファイル末尾を実行しません。CANCEL_PRINT／PAUSE／RESUMEの閉弁と退避、MCU shutdown時の液隔離、TMC故障原因、ホーミングのスイッチ動作、実ワークとの隙間・接触高さは引き続き未解決です。原点変更の符号だけを根拠に作業Zを変更していません。塗布部への追加開弁も行っていません。
